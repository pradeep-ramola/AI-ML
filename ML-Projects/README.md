# ML Projects Portfolio

This repository contains multiple machine learning projects demonstrating end-to-end workflows including data preprocessing, exploratory data analysis (EDA), model implementation, evaluation, and hyperparameter tuning.

Each project is self-contained in its own Jupyter notebook and focuses on a specific dataset or modeling task.

## Projects

1. **Simple Neural Network Classification**
   - **Notebook:** `simple_nn_classification.ipynb`
   - **Description:** Classification task using a dataset with features `f1` to `f7`. Covers preprocessing, EDA, SimpleNN implementation, training, testing, and hyperparameter tuning.

2. **ResNet-34 on Oxford Flowers**
   - **Notebook:** `resnet34_oxford_flowers.ipynb`
   - **Description:** Image classification using ResNet-34 implemented in PyTorch. Includes data preprocessing, augmentation, training, evaluation, and hyperparameter tuning.

3. **Logistic Regression on Multiple Datasets**
   - **Notebook:** `data_analysis_logistic_regression.ipynb`
   - **Description:** End-to-end workflow for Penguins, Diamonds, and Epicurious datasets. Includes preprocessing, EDA, logistic regression modeling, testing, and hyperparameter tuning.



## Requirements
- Python 3.8+
- Common libraries: `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `torch`, `torchvision` (depending on the project)
